✅ Round 2 — Technical Interview (TI-1)

This is the MOST IMPORTANT round for freshers.

What the interviewer focuses on:

Your thought process

Clean code (C++/Java/Python)

Basic CS fundamentals

Your B.Tech projects

Ability to explain logic clearly

Typical Technical Questions (Very Common)
DSA (must-know problems)

Reverse a linked list

Find middle of linked list

Detect loop in linked list

Binary search variations

Two-sum (hashing)

Move zeros to end

Longest substring without repeating characters

First non-repeating character in string

Anagram check

Leaders in array

Kadane’s algorithm (max subarray sum)
